# File names from titles (upstream #87)

Goal: a clear "Update to match title" action that renames the open entry's file to the slug of its title.

1. `src/lib/files/rename-to-title.ts` (+ tests): pure logic. `renameTargetFor` (null when no title, or the name already follows the title), `fileNameMatchesTitle` (sync, for the hint), `withSlugField`.
2. `src/lib/files/rename-to-title-action.ts` (+ tests): imperative action. Save unsaved edits, scan siblings, update `slug` field, save, `renameFile`, update the store, refresh the sidebar, toast "Renamed to x.md".
3. UI: hint under the title field (FrontmatterField/TextareaField), command palette entry "Rename File to Match Title", sidebar context-menu item.
4. Docs in `docs/developer/`, check:all, drive in the dev app.
