# Home screen and title-bar site switcher

Spec: `.superpowers/sdd/2026-11-04-four-features/home-brief.md` and the approved mockup.

1. Pure logic in `lib/projects/home.ts` (greeting, search threshold, card keyboard moves, recent sites) with tests first.
2. Actions in `lib/projects/actions.ts`: `openSite` and `goHome` (save, then close the project and stop its server). `projectStore.closeProject`; the app no longer reopens the last project at startup.
3. Previews: `lib/projects/previews.ts` wraps the previews engine commands (local stub until the engine's bindings are merged); a query hook and an event hook keep cards current.
4. UI: `components/home/` (HomeScreen, SiteCard, FirstLaunch) shown as an overlay in `Layout` while no project is open (panels stay mounted); title bar shows the app name and Settings on Home; `SiteSwitcher` replaces the plain site name in the editor.
5. Entry points: File menu Home (Shift+Cmd+H, Rust + JS), Windows menu, palette "Go Home". Remove the old welcome buttons.
6. Tests, docs, screenshots in the dev app (light and dark), `bun run check:all`.
